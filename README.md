# Team_Innovatrix
Build an AI-powered web application that reverse-engineers a user’s exact dream job into a highly interactive, personalised career roadmap.

Problem 1
🚀 PathForge AI

An AI-powered career roadmap builder that helps students plan their careers with personalized learning paths, interactive skill trees, action plans, and progress tracking.

✨ Features
- Personalized career roadmaps
- Interactive skill tree
- Action plans and progress tracking
- AI integration with demo mode

🛠️ Tech Stack
Next.js, React, TypeScript, Tailwind CSS, React Flow, OpenAI API.

## 🚀 Run Locally
```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

Note: Live AI features require a valid API key and available credits.
